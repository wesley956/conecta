# Proposed LG Content Store listing

## App name

RonecaPlayTV

## Short description

A secure media player for authorized live channels, movies, and series, with remote-friendly navigation and controlled device activation.

## Long description

RonecaPlayTV is a television media player designed for authorized content catalogs. Users activate their television through a controlled account portal and can browse live channels, movies, and series in a remote-friendly interface.

Main features include category navigation, search, favorites, viewing history, Continue Watching, episode navigation, audio and subtitle controls when available, configurable buffering, automatic reconnection, and controlled primary/backup catalog recovery.

RonecaPlayTV does not provide, sell, or bundle third-party commercial content. Access depends on an authorized catalog configured by the account provider.
